🚀 5 MINUTOS PARA EMPEZAR

Paso 1: Verificar que Redis está corriendo (2 minutos)
────────────────────────────────────────────────────

# Opción A: Redis Local
$ redis-server
# O
$ redis-cli ping
# Debe retornar: PONG

# Opción B: RedisCloud
# 1. Ir a https://redis.com/try-free/
# 2. Crear cuenta gratuita
# 3. Crear base de datos
# 4. Copiar URL: redis://default:xxxxx@host:port


Paso 2: Configurar variables de entorno (1 minuto)
──────────────────────────────────────────────────

$ cp .env.example .env

# Editar .env:
REDIS_URL=redis://localhost:6379    # o tu URL de RedisCloud
JWT_SECRET=tu_secreto_aqui
PORT=3000


Paso 3: Instalar dependencias (1 minuto)
────────────────────────────────────────

$ npm install


Paso 4: Iniciar servidor (1 minuto)
──────────────────────────────────

$ npm start

Verás:
╔════════════════════════════════════════╗
║ Servidor ejecutándose                  ║
║ http://localhost:3000                  ║
╚════════════════════════════════════════╝


🧪 PRUEBAS RÁPIDAS (en otra terminal)
═════════════════════════════════════

Opción A: Tests automatizados
$ bash test-api.sh

Opción B: Pruebas manuales con cURL

1️⃣ Obtener documentación
$ curl http://localhost:3000

2️⃣ Registrarse
$ curl -X POST http://localhost:3000/api/auth/registro \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "nombre": "Test User",
    "contraseña": "password123"
  }'

3️⃣ Login (copiar el token retornado)
$ TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "contraseña": "password123"
  }' | jq -r '.token')

$ echo $TOKEN

4️⃣ Crear tareas
$ curl -X POST http://localhost:3000/api/tareas \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Mi primera tarea",
    "prioridad": 5,
    "fechaVencimiento": "2024-01-10"
  }'

5️⃣ Ver tareas ordenadas por PRIORIDAD ⭐
$ curl -X GET "http://localhost:3000/api/tareas/ordenadas/prioridad?limit=5" \
  -H "Authorization: Bearer $TOKEN" | jq

6️⃣ Ver tareas ordenadas por FECHA 📅
$ curl -X GET "http://localhost:3000/api/tareas/ordenadas/vencimiento?limit=5" \
  -H "Authorization: Bearer $TOKEN" | jq

7️⃣ Limpiar tareas vencidas
$ curl -X DELETE http://localhost:3000/api/tareas/limpiar/vencidas \
  -H "Authorization: Bearer $TOKEN" | jq

🎯 CASOS DE USO

Caso 1: Dashboard de tareas pendientes
──────────────────────────────────────
$ curl "http://localhost:3000/api/tareas/ordenadas/vencimiento?limit=5" \

  -H "Authorization: Bearer $TOKEN"

❓ TROUBLESHOOTING
══════════════════

Error: "No conectado a Redis"
────────────────────────────
✅ Verifica que Redis está corriendo: redis-cli ping
✅ Verifica REDIS_URL en .env
✅ Si usas RedisCloud, copia correctamente la URL

Error: "Token inválido"
──────────────────────
✅ Asegúrate de copiar todo el token
✅ Formato debe ser: Authorization: Bearer {token}
✅ Verifica que el servidor aún está corriendo

Error: "Tarea no encontrada"
───────────────────────────
✅ Verifica el ID de la tarea
✅ Asegúrate de usar el mismo usuario (token)
✅ La tarea pudo haber sido eliminada

Error: npm install falla
────────────────────────
✅ Node.js v14+ requerido: node --version
✅ Borra node_modules: rm -rf node_modules
✅ Intenta de nuevo: npm install
